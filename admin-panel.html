CONFIGURACIÓN QR
Define la URL donde subirás el sistema para generar los QR correctos
¿CÓMO FUNCIONA?
1. Sube checkin.html a tu hosting.
2. Escribe aquí la URL completa donde quedó el archivo.
3. Los QR de cada cliente apuntarán a esa URL con su ID.
4. Al escanear → el cliente ve confirmación de entrada.
URL BASE DE TU HOSTING
El QR final se verá así:
ARCHIVOS NECESARIOS EN TU SERVIDOR
admin-panel.html
Este panel de administración
checkin.html
Página que ve el cliente al escanear
gym-data.json
Base de datos compartida entre ambos
⚠ IMPORTANTE
Para que el check-in funcione en tiempo real necesitas que tu hosting soporte PHP o Node.js para guardar datos. Si solo tienes HTML estático, los check-ins se mostrarán al cliente pero deberás registrarlos manualmente en el panel.
CONFIG. CORREO
Configura EmailJS para enviar correos automáticos de bienvenida
📋 GUÍA DE CONFIGURACIÓN — 5 PASOS
1
Crea cuenta en EmailJS
Ve a emailjs.com → Sign Up gratis (200 correos/mes incluidos)
2
Conecta tu correo (Email Service)
Email Services → Add New Service → elige Gmail u Outlook → conecta tu cuenta del gimnasio
3
Crea una plantilla (Email Template)
Email Templates → Create New → pega el contenido del botón de abajo → guarda con nombre gymtrack_bienvenida
4
Copia tus claves
Account → API Keys copia tu Public Key. Del servicio copia el Service ID. De la plantilla copia el Template ID
5
Pega las claves abajo y prueba
Llena los campos de abajo, guarda, y cada nuevo cliente recibirá su correo automáticamente al registrarse
